QUICK START GUIDE

How to Install RK Player on Windows

Getting started takes less than 60 seconds. Follow these 3 simple steps to start enjoying your music and videos.

01

Download Installer

Click the download button above to grab the official RK Player Setup 1.0.0.exe (or Portable RK Player 1.0.0.exe) directly to your PC.

02

Run Setup Wizard

Double-click the installer file. Follow the on-screen setup prompts to choose your preferred install folder and start menu shortcuts.

03

Play & Enjoy

Launch RK Player from your Desktop or Start Menu. Simply drag and drop any audio or video file or whole folder to start playing!

Windows SmartScreen notice: Because RK Player is a freshly built independent open-source release, Windows may display a blue warning dialog. Simply click "More info" and then "Run anyway". RK Player contains zero viruses, adware, or background tracking.
